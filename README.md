# SkyHint - Weather Dashboard

Experience real-time weather information with the SkyHint, a modern and responsive web application built with React. This application allows users to search for weather conditions in any city worldwide, providing current weather, hourly forecasts, and daily outlooks. Powered by the Open-Meteo API, SkyHint offers a clean, intuitive interface with dynamic backgrounds and interactive charts to visualize weather patterns.

## Features

- **Global City Search:** Easily find weather information for any city across the globe.
- **Current Weather:** View real-time temperature, weather conditions, humidity, wind speed, and pressure.
- **Hourly Forecast:** Get detailed weather predictions for the next 24 hours, including temperature, precipitation chances, and weather icons.
- **Daily Forecast:** Plan your week with a 7-day weather outlook, showing high/low temperatures and general conditions.
- **Dynamic Backgrounds:** Enjoy a visually appealing experience with backgrounds that adapt to current weather conditions.
- **Responsive Design:** A seamless experience across various devices and screen sizes.
- **Error Handling & Loading States:** Clear feedback for users during data fetching or in case of errors.

## Technologies Used

- **React:** A JavaScript library for building user interfaces.
- **Vite:** A fast build tool that provides an optimized development experience.
- **Tailwind CSS:** A utility-first CSS framework for rapidly building custom designs.
- **Framer Motion:** A production-ready motion library for React.
- **Open-Meteo API:** Provides free weather forecast and geocoding data without requiring an API key.

## Installation

To get a local copy up and running, follow these simple steps.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/saksham2882/weather-info.git
    cd weatherInfo
    ```
2.  **Install NPM packages:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm run dev
    ```
    The application will be accessible at `http://localhost:5173` (or another port if 5173 is in use).

## Usage

1.  **Search for a City:** Use the search bar at the top of the dashboard to enter the name of a city.
2.  **View Weather Data:** Once a city is selected, the dashboard will display the current weather, hourly forecast, and daily forecast.
3.  **Explore Forecasts:** Scroll through the hourly and daily forecast sections to get detailed information.
